## Cómo entregar (todo el semestre)

1. Haz **fork** de este repositorio (o clona si tienes acceso de escritura).
2. Crea una rama con tu nombre o el de tu equipo: `equipo-1-s2`, `nombre-lab1a`, etc.
3. Trabaja dentro de la carpeta correspondiente. **No borres ni modifiques
   las plantillas originales** — cópialas dentro de tu carpeta de entrega.
4. Abre un **Pull Request** hacia `main` antes del cierre de cada sesión
   o de la fecha límite del laboratorio. El PR es la evidencia de entrega.
5. Completa la sección de **bitácora de delegación** (ver
   [`docs/politica-ia.md`](docs/politica-ia.md)) al final de tu entregable.
